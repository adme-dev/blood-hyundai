# Project Brief

## Project Name
**blood-hyundai / drive-agent**

## Core Purpose
A comprehensive automotive dealership website and vehicle management platform for Waverley Nissan, built to provide customers with a complete digital experience for browsing, comparing, and purchasing vehicles online.

## Primary Goals
1. **Vehicle Search & Discovery**: Enable customers to search, filter, and browse new, demo, and used vehicles with sophisticated filtering capabilities
2. **Vehicle Build & Configuration**: Allow customers to build and customize their ideal vehicle with real-time pricing
3. **E-commerce Integration**: Facilitate vehicle deposits, payments, and secure transactions through Stripe integration
4. **Lead Generation**: Capture customer enquiries for test drives, service bookings, parts orders, and vehicle sales
5. **Content Management**: Display dynamic content including special offers, vehicle models, and dealership information

## Target Users
- Car buyers seeking new, demo, or used vehicles
- Existing customers needing service or parts
- Sales staff managing inventory and customer interactions
- Dealership administrators managing content and offers

## Key Requirements
- Advanced vehicle search with multiple filter types (text, checkbox, slider, date ranges)
- Stock ID search supporting multiple vehicles (comma-separated)
- Vehicle comparison functionality
- Build and price configurator
- Payment processing via Stripe
- Google reviews integration
- Social media integration (Facebook, YouTube)
- SEO-optimized pages with dynamic meta tags
- Mobile-responsive design using UIKit framework

## Technical Constraints
- Must work with legacy Node.js requiring `--openssl-legacy-provider` flag
- Hosted on Netlify with serverless functions
- Vue.js 2.x architecture (not Vue 3)
- Integration with external driveagent-ui component library

## Success Criteria
- Fast, responsive vehicle search with sub-second results
- Intuitive filtering with real-time results
- Successful payment processing
- SEO-friendly URL structure
- Mobile-first responsive design
